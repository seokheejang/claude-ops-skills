# ralph — Domain Checklists

작업 도메인별 검증 체크리스트. ralph Phase 2에서 작업 내용에 따라 해당 섹션만 로드.

> 이 체크리스트는 "모델이 모르는 지식"을 적어두는 곳이 아니다. **판정 단위를 쪼개는 장치**다 — 항목이 있어야 라운드마다 PASS/FAIL 이 한 건씩 나온다. 그래서 일반적인 항목이어도 기능한다. 다만 **동어반복은 판정이 되지 않으므로** 넣지 않는다.

## 도메인 감지

작업 설명/대상 파일을 보고 아래 중 가장 가까운 도메인을 선택. 복수 해당 시 모두 적용.

| 신호 | 도메인 |
|------|--------|
| `.go`, `.ts`, `.py`, `.rs`, `.js`, `.sh` 등 코드 파일 / "함수", "구현", "리팩토링" | 코드 작성/수정 |
| `kubectl`, `helm`, `terraform`, `argocd`, `Chart.yaml`, `*.tf`, manifest, RBAC | DevOps/IaC |
| 장애 원인 규명, 로그/메트릭 해석, "왜 이런가", 가설 검증, 조사 결과 정리 | **분석/디버깅** |
| `*.md`, `settings.json`, config 파일, "문서", "정리" | 설정/문서 |
| 위 어디에도 안 맞을 때 | 범용 |

## 코드 작성/수정

- [ ] 빌드/lint 통과 (실제로 돌려본 결과인가, 돌려봤다고 가정한 것인가)
- [ ] 수정한 함수의 **다른 호출부**도 같이 확인했는가 (한 곳만 고치고 형제 호출부를 방치하지 않았는가)
- [ ] 보안: injection, 하드코딩된 credential, 경로 탈출
- [ ] 엣지 케이스: 빈 입력, 0/음수, 경계값, 에러 경로
- [ ] 기존 코드의 관례를 따랐는가 (새 패턴을 도입했다면 근거가 있는가)

## DevOps/IaC (K8s, Helm, Terraform, ArgoCD)

- [ ] READ-ONLY 안전 규칙 준수 (mutating 명령어 없음)
- [ ] **settings.json deny 규칙과 SKILL.md 금지 목록이 일치**하는가
- [ ] 하드코딩된 시크릿/경로/IP 없음
- [ ] 권한이 최소 범위로 제한됨 (RBAC, IAM)
- [ ] 예시 값이 제네릭명 사용 (`my-cluster`, `my-app`, `<DB_PASSWORD>` 등)
- [ ] 커밋 대상이면 **`scripts/pre-commit.sh` 훅이 못 잡는 2항목**을 수동 확인 — 예시 파일 일반화, `.gitignore` 상태 (CLAUDE.md "Commit / PR 시 보안 체크리스트")

## 분석/디버깅

증거 규율의 축약본이다. 깊은 장애 분석은 [troubleshoot](../../troubleshoot/) 스킬이 담당하고, 여기서는 **이미 낸 분석 결과를 재검증**한다.

- [ ] 모든 단정이 **실제로 관찰된 출력**에 근거하는가 (본 적 없는 값을 "확정"이라 적지 않았는가)
- [ ] **확정 / 유력 / 가설**이 구분 표기되어 있는가 (근거 칸이 빈 행이 "확정"으로 올라가 있지 않은가)
- [ ] **대안 원인을 최소 1개** 세우고 증거로 배제했는가 (단일 증거로 단정하지 않았는가)
- [ ] 조치를 제안했다면 **차단 / 완화 / 근본** 중 무엇인지 분류했는가
- [ ] 출처가 붙어 있는가 — 어느 대상(컨텍스트·호스트·IP·포트)에서 **언제** 받은 값인지
- [ ] 확인 못 한 것이 `(미확인)`으로 드러나 있는가 (추측으로 메워지지 않았는가)

## 설정/문서

- [ ] 다른 파일과 일관성 (네이밍, 컨벤션, 참조 경로)
- [ ] **링크와 참조 경로가 실재하는가** (삭제된 파일을 가리키고 있지 않은가)
- [ ] 문서에 적힌 절차가 실제 구현과 일치하는가 (문서와 구현이 다르면 구현이 맞다)
- [ ] 누락 항목 없음

## 범용 (위에 해당 없을 때)

- [ ] 사용자가 요청한 범위를 **전부** 처리했는가 (일부만 하고 완료 보고하지 않았는가)
- [ ] 요청하지 않은 것을 임의로 추가하지 않았는가
- [ ] 되돌리기 어려운 작업을 확인 없이 하지 않았는가
